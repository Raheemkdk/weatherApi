# 🌤️ Weather API | JavaScript Weather Application

A browser-based weather application built with **HTML, CSS, and JavaScript** that allows users to search for weather information by city and country.

This project demonstrates frontend development, API integration concepts, user input handling, and dynamic webpage design.

Live Link: https://rkweatherap.netlify.app/

## 🌟 Project Overview

Weather API is a web development project focused on retrieving and displaying weather information for locations around the world.

Users enter a city and country, then submit their search to request weather information.

The application's interface includes dedicated areas for displaying the selected location, weather conditions, a weather image, and temperature in Fahrenheit.

Originally developed as part of the **Resilient Labs Weather API Bootcamp Challenge**.

## ✨ Features

- **City search:** Input field for entering a city name.
- **Country search:** Input field for specifying a country.
- **Weather display:** Dedicated interface for displaying weather information.
- **Fahrenheit temperature:** Designed to show temperatures in Fahrenheit.
- **Weather imagery:** Includes an image element for representing weather conditions.
- **Interactive search:** Button for initiating a weather lookup.
- **Custom styling:** CSS-based interface with rounded input fields and buttons.
- **Weather favicon:** Custom icon displayed in the browser tab.

## ⚙️ Application Workflow

The intended application workflow is:

1. The user enters a city name.
2. The user enters a country name.
3. The user clicks the search button.
4. JavaScript processes the entered location.
5. The application requests weather data from an external API.
6. The results are displayed in the weather information section.

The interface is designed to present the location and current temperature in Fahrenheit.
